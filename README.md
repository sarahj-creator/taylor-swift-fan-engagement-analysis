# Taylor Swift Fan Engagement Analysis

## Project Overview
Analysis of fan engagement patterns comparing narrative-driven songs vs. pop anthems using YouTube comment data.

## Key Findings
- Narrative songs generate 7x more lore-related discussion (51% vs 7.2%)
- Lore comments receive 3x higher community validation (likes)
- Storytelling creates fundamentally different fan communities

## Data Sources
- YouTube Data API v3
- Comments from "All Too Well (10 Minute Version)" vs "Shake It Off"

## Technologies Used
- Python
- Pandas, Matplotlib, Seaborn
- Google API Client
- Jupyter Notebook
